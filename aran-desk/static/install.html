Install Aran Vault on a test phone

Sideloads the vault app onto the connected phone and grants it notification access, so you can test live abuse capture. Use your own test device.

This writes to the phone. Unlike the read-only scanner, this installs an app. Only run it on a device you own and control for testing.
Looking for a phone…USB cable, USB debugging on, then tap “Allow”.

    After install — on the phone
    1. Open the Calculator (the vault's disguise), type the PIN to reveal the vault.
    2. If notification access wasn't granted automatically: Settings → Notifications → Notification access → enable Aran Vault.
    3. On ColorOS: Settings → Battery → allow background activity for Aran Vault.
